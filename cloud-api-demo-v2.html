Demo page for Cloud Camera API integration - live video streaming from cloud-connected devices, with live object detection, license-plate recognition, and point-of-sale analytics delivered over the same WebSocket.

☁️ Cloud API:
HTTPS Required
  • All API requests use https://api.cloud.dividia.net
  • WebSocket H.264 streaming via WSPlayer.js
  • JWT Bearer token authentication

code base: https://github.com/dividia-dev/api

Endpoint: POST /ve/auth

Authenticates a user and returns access token plus authorized devices and cameras for streaming.

Request Body (JSON)
FieldTypeDescription
usernamestringUser email address
passwordstringUser password
Response
FieldTypeDescription
tokenstringJWT token for authenticated requests (30-day expiry)
devicesarrayList of devices (sDeviceID, sName, fOnline)
camerasarrayList of cameras (sDeviceID, bCamera, bProfile, sName, fEnabled, fOnline)

Device & Camera Data Structure

Device Object
FieldTypeDescription

fOnlineint1 = online, 0 = offline
Camera Object
FieldTypeDescription
sDeviceIDstringParent device serial
bCameraintCamera number (1-16) - used in WebSocket URL as cam{N}
bProfileintStream profile (1=full, 2=lower) - used in WebSocket URL as pro{P}
sNamestringCamera display name
fEnabledint1 = enabled, 0 = disabled
fOnlineint1 = online, 0 = offline
