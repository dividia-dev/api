Dividia NVR API Demo

View API Reference

Demo page for API integration - live video streaming and recorded video playback.

🌐 Deployment Options:
HTTP Version (Local Network)
  • Use local IPs (192.168.x.x)
  • MJPEG & JPEG viewers only
  • No WebSocket H.264 (unless localhost)
HTTPS Version (Remote Access)
  • Use serial.dvr.dividia.net URLs
  • All viewers supported
  • WebSocket H.264 available

Note: This page auto-detects its protocol and configures accordingly. Deploy same codebase to both HTTP and HTTPS servers.

code base: https://github.com/dividia-dev/nvr-api-demo
