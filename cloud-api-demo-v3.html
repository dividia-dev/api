Endpoint: POST /sw/api/auth

Signs in a ScaleWatcher API user (email + password) and returns the long-lived API token plus the sites on its key. Keep this token on your server.

Endpoint: POST /sw/api/video-token

With Authorization: Bearer <API token> and exactly one of locationId (your Command location.id), deviceId or serial, returns a view-only stream URL for that site's cloud device. All three give the same device and stream. The URL can start a stream for 10 minutes; a playing stream keeps playing until its access is revoked.

StatusreasonWhen
403video_not_allowedThe API user doesn't have Live video (a Dividia user turns it on)
404site_not_foundNo site in this key's site list matches
409ambiguous_locationThe location.id belongs to more than one customer's site on this key; retry with a listed serial
409no_cloud_videoThe site's NVR is not a cloud device with live video

If the stream is stopped, the player shows why: token_expired (mint a new URL), video_access_revoked, site_access_revoked, api_key_revoked.
