GET /sw/api/transactions

Retrieve transaction records. Transactions represent complete scale weighing cycles.

Parameters
ParameterTypeDescription
serial *integerSite serial number
startDatedateFilter start (YYYY-MM-DD)
endDatedateFilter end (YYYY-MM-DD)
scaleintegerScale number
lpnstringLicense plate
ticketintegerTicket number
tagstringVehicle type: truck, car, other, pending
includeEvents0|1Include events
includeAlerts0|1Include alerts
pageintegerPage number
pageSizeintegerResults per page (default: 50,000 if not specified)
Response includes:

id, bSerial, bScale, dTimestamp, dStart, dEnd, sLpn, sTruck, bTicket, bFacilityDuration, bLoadDuration, bWaitDuration, fHidden, sTag
