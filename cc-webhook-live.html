How to send tickets to Dividia

Your system sends each ticket to Dividia as one web request. Build it in this order:

  1. What Dividia gives you: an address, a customer id and a signing secret
  2. The body: the ticket itself
  3. The headers: labels sent with the body, three of them made new for every ticket
  4. Send a ticket: sign it with your secret and send it, shown step by step
  5. Read it back: the ticket's data and PDF

Step 1 · What Dividia gives you

Addresshttps://api.cloud.dividia.net/sw/webhooks/cc
Send every ticket here, as an HTTPS POST. It is the same for every customer.
Customer idA GUID, for example 3f2b8c1e-7d4a-4e9b-a6c2-91d0e5f4b8a7.
It goes in the Dividia-Customer-Id header.
Signing secretStarts with whsec_. Keep it private.
Your system uses it to make the signature (step 3). It is never sent.

Step 2 · The body: the ticket

The body is the ticket, as JSON. These fields matter to Dividia; send everything else your ticket has too.

uniqueIdThe ticket's own id. New for every ticket: a second ticket with the same uniqueId is ignored, so resending is safe.
ticketNumberThe ticket number. Required.
ticketDateTimeThe ticket's date and time
location.idWhich site the ticket is for
location.nameThe site's name, for display
scaleIdWhich scale weighed the truck
Everything elseThe ticket's details: vehicle, weights, customer, carrier, product and so on
For example
{ "uniqueId": "3f2b8c1e-7d4a-4e9b-a6c2-91d0e5f4b8a7", "ticketNumber": "322780035", "ticketDateTime": "2026-10-26T13:53:00Z", "location": { "id": "IQ-001", "name": "North Yard" }, "scaleId": "IQ-001", "vehicle": { "id": "VEH-7908", "name": "Freightliner Cascadia" }, "product": { "id": "PRD-766", "name": "Fill dirt" } }

Step 3 · The headers

Headers are labels sent along with the body. Every ticket carries these:

HeaderWhat it is
Dividia-Customer-IdYour customer id from Dividia. Type it in once.
Content-Typeapplication/json. Type it in once.
webhook-idAn id for this ticket. Easiest: use the ticket's uniqueId. Any text works, with no set format or length; a GUID such as 3f2b8c1e-7d4a-4e9b-a6c2-91d0e5f4b8a7 is fine. Use the same id here and in the signature.
webhook-timestampThe time the ticket is sent, as a number of seconds (often called Unix time or epoch seconds): 10 digits, for example 1793022780. Made new for every ticket, and it must be within 5 minutes of the real time.
webhook-signatureA code made from the ticket and your signing secret. It proves the ticket came from you. Made new for every ticket.
How the signature works

The signing secret is like a password that only you and Dividia have. For each ticket, your webhook system takes three things, the webhook-id, the webhook-timestamp and the body, joins them with dots, and mixes them with the secret to make a code. It sends that code as webhook-signature. Dividia makes the same code with its copy of the secret. If the two match, the ticket is accepted; if not, it is refused (HTTP 401). The code is different for every ticket, so it can't be typed in once.

Dividia follows the Standard Webhooks format. Its spec explains these headers and the signature in full (each link opens in a new tab): the webhook headers · how the signature is made · how webhooks are verified · standardwebhooks.com (with ready-made libraries for most languages).

Never put the signing secret in a header.
The secret is never sent. Your webhook system keeps it and uses it to make webhook-signature for each ticket. If your webhook settings only let you type in fixed headers, they cannot make the last three: look for a setting to sign webhooks (the "Standard Webhooks" format) and put the signing secret there.

Step 4 · Send a ticket

The request is built here the way your system must build it: the headers, then the body. The three webhook headers fill in as you type. Press Send ticket to send it as a real ticket for that site.

Headers

webhook-signature = v1, + Base64( HMAC-SHA256( key, webhook-id + . + webhook-timestamp + . + body ) )
where key = the signing secret after whsec_, Base64-decoded. See it worked out for this ticket · Standard Webhooks signature spec

What Dividia's answers mean
  • delivered: the site has the ticket and photographs the scale
  • fallback: stored without photos (the reason says why)
  • failed: this location.id is not set up
  • duplicate: Dividia already has this uniqueId (what sending the same ticket again gets; press New ticket for a new one)
  • A 400 or 401 means fix the request. A 429 or 5xx means send it again with the same uniqueId.

Step 5 · Read it back (public API)

Paste the public-API token of an API user that can see the site: the long value in three parts separated by dots that was emailed with the API key. It goes only to Dividia, as the Bearer token. The public API returns real tickets only, so read back a ticket sent from this page, not one from Dividia's internal test console.

For developers: code to send a ticket

Drop-in code with no extra packages. Call sendTicket(ticket) (Node.js) or send_ticket(ticket) (Python) once for every ticket: it makes the three webhook headers and sends the ticket. Set your customer id and signing secret as the environment variables DIVIDIA_CUSTOMER_ID and DIVIDIA_SECRET.

Node.js 18 or later: send-ticket.js
// send-ticket.js: send a ticket to Dividia. Node.js 18+, no packages. // Run: DIVIDIA_CUSTOMER_ID='your-customer-id' DIVIDIA_SECRET='whsec_...' node send-ticket.js const crypto = require('crypto'); const WEBHOOK_URL = 'https://api.cloud.dividia.net/sw/webhooks/cc'; const CUSTOMER_ID = process.env.DIVIDIA_CUSTOMER_ID; // your customer id from Dividia const SECRET = process.env.DIVIDIA_SECRET; // whsec_...: it signs and is never sent // Signs one ticket and sends it. Call it once for every ticket. async function sendTicket(ticket) { const body = JSON.stringify(ticket); // sign and send this exact text const id = ticket.uniqueId; // webhook-id const timestamp = Math.floor(Date.now() / 1000).toString(); // webhook-timestamp, in seconds const key = Buffer.from(SECRET.replace(/^whsec_/, ''), 'base64'); const signature = 'v1,' + crypto.createHmac('sha256', key) .update(id + '.' + timestamp + '.' + body).digest('base64'); const res = await fetch(WEBHOOK_URL, { method: 'POST', headers: { 'Content-Type': 'application/json', 'Dividia-Customer-Id': CUSTOMER_ID, 'webhook-id': id, 'webhook-timestamp': timestamp, 'webhook-signature': signature, }, body, }); return { status: res.status, answer: await res.text() }; } // Example: one ticket. Send your own ticket data the same way. sendTicket({ uniqueId: crypto.randomUUID(), // new for every ticket ticketNumber: '322780035', ticketDateTime: new Date().toISOString(), location: { id: 'IQ-001', name: 'North Yard' }, scaleId: 'IQ-001', vehicle: { id: 'VEH-7908', name: 'Freightliner Cascadia' }, }).then(r => console.log(r.status, r.answer)); // 200 {"status":"delivered"}
Python 3.9 or later: send_ticket.py
# send_ticket.py: send a ticket to Dividia. Python 3.9+, no packages. # Run: DIVIDIA_CUSTOMER_ID='your-customer-id' DIVIDIA_SECRET='whsec_...' python3 send_ticket.py import base64, hashlib, hmac, json, os, time, uuid import urllib.error, urllib.request WEBHOOK_URL = "https://api.cloud.dividia.net/sw/webhooks/cc" CUSTOMER_ID = os.environ["DIVIDIA_CUSTOMER_ID"] # your customer id from Dividia SECRET = os.environ["DIVIDIA_SECRET"] # whsec_...: it signs and is never sent def send_ticket(ticket): """Signs one ticket and sends it. Call it once for every ticket.""" body = json.dumps(ticket) # sign and send this exact text msg_id = ticket["uniqueId"] # webhook-id timestamp = str(int(time.time())) # webhook-timestamp, in seconds key = base64.b64decode(SECRET.removeprefix("whsec_")) digest = hmac.new(key, f"{msg_id}.{timestamp}.{body}".encode(), hashlib.sha256).digest() signature = "v1," + base64.b64encode(digest).decode() request = urllib.request.Request(WEBHOOK_URL, data=body.encode(), method="POST", headers={ "Content-Type": "application/json", "Dividia-Customer-Id": CUSTOMER_ID, "webhook-id": msg_id, "webhook-timestamp": timestamp, "webhook-signature": signature, }) try: with urllib.request.urlopen(request) as res: return res.status, res.read().decode() except urllib.error.HTTPError as err: return err.code, err.read().decode() # Example: one ticket. Send your own ticket data the same way. print(*send_ticket({ "uniqueId": str(uuid.uuid4()), # new for every ticket "ticketNumber": "322780035", "ticketDateTime": time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime()), "location": {"id": "IQ-001", "name": "North Yard"}, "scaleId": "IQ-001", "vehicle": {"id": "VEH-7908", "name": "Freightliner Cascadia"}, })) # 200 {"status":"delivered"}
